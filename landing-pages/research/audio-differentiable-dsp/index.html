Research Track C · complete

Neural methods inside the DSP toolbox.

Make classical audio building blocks (oscillators, filters, reverbs, compressors, physical models) differentiable so their parameters can be learned from audio; invert synthesizers and effects, from a sound back to the settings that made it; and combine physics with learned parts.

For signal-processing people, acousticians and instrument builders who want the neural part to be a thin, legible layer on top of the DSP rather than a replacement for it.

Before you start

What the track assumes

JOS's books, as the four tutored book courses: Introduction to Digital Filters and Spectral Audio Signal Processing for course 1, SASP for course 2, and Physical Audio Signal Processing for course 3. Read as far as you need and come back. On the machine-learning side, AI Foundations through its PyTorch phase is enough.

The courses

Three courses, one note

Each course takes the same note further: from resynthesis, to inverting the synthesizer, to modeling the physical object.

Course 1 · audio-ddsp

Differentiable DSP

Harmonic oscillators, filtered noise and reverb with learned control (DDSP), why waveform loss fails and spectral losses work, differentiable IIR filters and biquads, all-pass and grey-box effects, then DDX7, DDSP-Piano and MIDI-DDSP.

The differentiable block: which block, and which loss.

~20–25 sessions
Course on GitHub
Course 2 · audio-synth-effect-matching

Synth and Effect Matching

Sound matching as an inverse problem: handcrafted features, supervised prediction, the loss question, differentiable synth matching, generative and RL estimators, and effect inversion, through the DAFx26 papers and challenge.

Many parameters, one sound.

~25–30 sessions
Course on GitHub
Course 3 · audio-physics-informed

Physics-Informed Audio

Physics plus learning on one note, three ways: a learnable modal resonator bank, a physics-informed network for the damped stiff string, and hybrid physical and neural models.

The physical prior as inductive bias: where does the network go?

~18–22 sessions
Course on GitHub

Get started

One line to install every course

Install Claude Code (it runs in a terminal and in the Claude desktop app's Code tab, and needs a Claude account), then paste this into a terminal, once:

claude plugin marketplace add https://github.com/josmithiii/Courses && claude plugin install courses@josmithiii-courses

Then start a session in any folder and say let's do today's audio-ddsp lesson, or name any course on this page.

The courses are free and open, and the full track plan is in the Differentiable & Physical Audio DSP curriculum. The tutor runs on your own Claude account, and your progress stays in a folder on your own computer.
