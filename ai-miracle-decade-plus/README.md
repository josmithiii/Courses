# AI Miracle Decade+

A self-paced reading of every landmark AI paper from DBN (2006) to GPT-4
(2023). Forty papers, seven cross-cutting concept threads, no time
budget.

## Where to start

- **One-screen visual overview** — <https://josmithiii.github.io/ai-miracle-decade-plus/>
- **Full prose curriculum** — [`curriculum.md`](curriculum.md)
- **Take the course interactively** —

  ```bash
  cd ai-miracle-decade-plus
  claude        # launches Claude Code in this folder
  /lesson       # begins (or resumes) the next stop
  ```

  The `/lesson` tutor reads your private `progress.md` (seeded on first
  run from [`progress.template.md`](progress.template.md)) and walks you
  through one stop at a time. Side quests are first-class — when a paper
  hooks you, the tutor logs the detour and the roadmap pulls you back
  so nothing important gets quietly skipped.
