# AI Foundations
*The on-ramp — complete beginner → modern LLMs.*

From the Multilayer Perceptron up to modern LLMs: backprop, PyTorch, CNNs,
Transformers, LLMs, and diffusion. Intuition-first — visuals and analogies before
notation, with Python and math taught *just-in-time* as each concept needs them.

**Approach:** one concept at a time, ~1 hr/day; every concept checked with a small
exercise before moving on. New to ML, new to Python, rusty math — all fine.

**Prerequisites:** none. This is the entry point the AI Music & Audio thread builds on.

**Start:** clone **[Courses](https://github.com/josmithiii/Courses)**, then
`./take ai-foundations` (launches the daily lesson in
[Claude Code](https://claude.com/claude-code)). Full detail in [`syllabus.md`](syllabus.md).
